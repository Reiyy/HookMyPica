## 简介 

本仓库为 [哔咔桥PicaBridge](https://github.com/Reiyy/PicaBridge) 的配套MyPica App所需要的XP模块发布仓库。  
关于主项目的更多详情，请查看：[哔咔桥PicaBridge](https://github.com/Reiyy/PicaBridge)

本模块用于给MyPica实现自定义功能，基于 [HookPicACG](https://github.com/AoEiuV020/HookPicACG) 修改而来。

可直接使用的，LSPatch打包版本也在此仓库的Releases发布。

## 支持的版本

PicaBridge 0.7.51+
